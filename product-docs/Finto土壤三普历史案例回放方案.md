# Finto 土壤三普历史案例回放方案

> 用途：用本人参与过的去标识化历史项目验证 Finto 的业务价值。
>
> 证据性质：历史案例回放和本人持续使用，不是外部用户试用。
> 隐私要求：不记录真实地区、单位、人员姓名、内部编号、坐标、未公开数据或可反推项目的信息。

## 一、执行规则

1. 每个案例先在 Finto 之外建立一份人工基线，再运行 Finto，避免用系统结果反向定义“正确答案”。
2. 原始资料只使用确认可以保存的去标识化副本；资料名称也应去标识化。
3. 每个确定字段必须有 `source_id + locator + excerpt`；没有依据的内容进入待补充与确认。
4. AI 或本地规则只生成候选；人工决定后才形成正式 Revision。
5. 发生变更时必须创建新 Revision，并确认旧版本仍可打开。
6. 耗时使用计时器真实记录；未计时的案例不得填写推算值或节省比例。
